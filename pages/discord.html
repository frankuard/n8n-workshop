Part 3: Discord Automation

Extend our AI workflow by sending automated notifications to Discord.

14. (Optional) Add Discord Automation

We can extend our AI automation by connecting it to Discord.

This allows the AI-generated student request to be displayed automatically inside a Discord channel.

Student Form → AI / Groq → Gmail + Discord

14.1 Why Discord?

Discord can be used as a notification platform for our automation.

Instead of checking email every time, a team can receive a notification directly inside a Discord channel.

Example:

You submit a leave request → AI processes it → Gmail sends the email → Discord receives a notification.

14.2 Add the Discord Node

  1. Open your existing n8n workflow.
  2. Click the + button.
  3. Search for Discord.
  4. Add the Discord node.
  5. Configure your Discord credentials.

14.3 Configure the Discord Server

Your Discord bot or integration needs access to the Discord server where you want to send the message.

Select the Server

Choose the Discord server that you want to use for the workshop.

Select the Channel

Choose the channel where n8n should send the automated message.

Important:

Make sure the Discord integration has permission to view and send messages in the selected channel.

14.4 Create the Discord Message

The Discord node can receive information from the previous AI node.

We can create a message containing:

  • Student name
  • Department
  • Subject
  • AI-generated email

Example Discord Message

New Student Request

Student: Hari Bahadur

Department: SSD

Subject: Leave Request

AI-generated email:

Dear SSD,

I am feeling unwell today and will not be able to attend my classes. I would therefore like to request leave for today.

I would be grateful if you could kindly consider my request.

Thank you for your understanding.

Kind regards,
Hari Bahadur

14.5 Connect AI to Discord

Connect the AI processing node to the Discord node.

Student Form → Basic LLM Chain → Discord

At the same time, the AI output can also continue to the Gmail node.

AI Output → Gmail + Discord

14.6 Final Discord Workflow

Student Form → AI / Groq → Gmail + Discord
Optional:

Discord is an extension to our main workflow. The core AI + Gmail automation can work without it.
