4. Part Two: Add AI

In Part 1, we created a basic automation where a student submits a form and n8n sends the information through Gmail.

Now we are going to make the workflow smarter by adding Artificial Intelligence.

Instead of simply sending the student's original message, AI will understand the student's request and turn it into a clear, polite, and professional email.

The idea:

Student writes normally → AI understands the request → AI creates a professional email → Gmail sends it automatically.

6. Add the Basic LLM Chain

The next step is to add an AI node to our n8n workflow.

n8n provides a node called Basic LLM Chain which allows us to tell an AI model what we want it to do.

Add the Node

  1. Open your n8n workflow.
  2. Click the + button.
  3. Search for Basic LLM Chain.
  4. Add the node to your workflow.

Connect the Form

Connect the output of your student form to the Basic LLM Chain.

Student Form → Basic LLM Chain

Add the Groq Chat Model

The Basic LLM Chain needs a language model to generate the response.

For this workshop, we will use Groq.

  1. Open the Basic LLM Chain node.
  2. Find the model input.
  3. Select Groq Chat Model.
  4. Connect the Groq Chat Model to the model input.

Groq Console

Open the Groq Console:

https://console.groq.com/

Create a Groq API Key

  1. Sign in to your Groq account.
  2. Open the API Keys section.
  3. Create a new API key.
  4. Give the key a name such as n8n-workshop.
  5. Copy the generated API key.

Important Security Rule

Never share your API key.

  • Do not post it on GitHub.
  • Do not send it to other people.
  • Do not include it in public screenshots.
  • Do not hard-code it inside public code.

Configure Groq in n8n

  1. Open the Groq Chat Model node.
  2. Create a new Groq credential.
  3. Paste your Groq API key.
  4. Save the credential.
  5. Select an available chat model from the model dropdown.

Understand the Two Nodes

Basic LLM Chain

The Basic LLM Chain controls what we want the AI to do.

Groq Chat Model

The Groq Chat Model provides the language model that generates the response.

Student Form → Basic LLM Chain ↑ Groq Chat Model

7. AI Prompt

The prompt is one of the most important parts of the AI automation.

It tells the AI what role it has, what information it receives, and exactly how it should respond.

Copy this prompt into the Basic LLM Chain 

You are an AI email assistant for college students. Your job is to
take a student's request, question, complaint, or concern and turn it
into a clear, polite, and professional email that can be sent to the
college department or faculty selected by the student.

Student Information:

Name:
{{ $json['Student Name'] }}

Email:
{{ $json['Faculty Email'] }}

Department / Faculty:
{{ $json['Department'] }}

Subject:
{{ $json['Subject'] }}

Student's Request:
{{ $json['What do you need?'] }}

Instructions:

1. Carefully understand what the student is trying to communicate.

2. Rewrite the student's request into a clear, polite, and
professional email suitable for communication with a college
department or faculty.

3. Keep the student's original meaning and intention.
Do not change what the student is asking for.

4. The request may involve any normal college-related matter,
including leave requests, academic questions, examination issues,
document requests, technical problems, fee-related questions,
complaints, or general concerns.

5. Address the selected department or faculty appropriately.

6. Use a respectful, friendly, and professional tone.

7. Make the request clear and easy for the recipient to understand.

8. Do not invent information, policies, dates, decisions, excuses,
or other details that the student did not provide.

9. Do not promise that the request will be approved or accepted.
The selected department or faculty will make the final decision.

10. If the student's request is unclear, do not invent missing
details. Keep the wording general and politely ask the department
or faculty for clarification if necessary.

11. Keep the email reasonably concise.
Do not make it unnecessarily long.

12. End the email politely with the student's name.

13. Return only the email body.

14. Do not include the subject line, explanation, analysis,
or any additional commentary.

The final output should be a natural, respectful email that is
ready to be sent to the selected college department or faculty.

  2. n8n receives the information.

12. The Important Difference

Basic Automation AI Automation
Sends the student's original message Understands and rewrites the message
Fixed message AI-generated message
Limited language understanding Natural language understanding
Mainly follows predefined instructions Can interpret different student requests
No AI model Uses a language model

The Main Idea

Traditional automation follows predefined rules.

AI automation allows the workflow to understand natural language and generate useful responses.

Automation + AI = Intelligent Automation
