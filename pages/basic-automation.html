Part 1: Basic Automation

Build your first n8n automation by connecting a student form to Gmail.

1. Part One: Basic Automation

In this part, we will create our first simple automation using n8n.

The goal is to allow a student to submit a form and automatically send that information through Gmail.

Basic idea:

Student fills the form → n8n receives the information → Gmail sends the email automatically.

2. Create the Form with whatever field that you desire

The first step is to create a form that collects the information required to send the gmail.

3. Connect the Form to Gmail

Once the form has been created, we can connect it to Gmail. This allows n8n to automatically send an email whenever a student submits the form.

Student Form → Gmail

Gmail Configuration

Add a Gmail node after the Form Trigger node.

The Gmail node will take the information received from the form and use it to send an email automatically.

Connected Account

In the Gmail node, find the Credential section and click Create New Credential.

Example account:

example123@gmail.com

Set Up Gmail Credentials

  1. Open the Gmail node in n8n.
  2. Under Credential, click Create New Credential.
  3. n8n will open the Google authentication page.
  4. Sign in using the Google account that you want to connect to n8n.
  5. Review the requested permissions.
  6. Allow n8n to access the required Gmail functionality.
  7. Return to n8n and confirm that your Gmail credential is connected successfully.
Important:

Never share your Google password, Gmail credentials, API keys, or other private authentication information with other participants.

Each participant should connect their own authorised Gmail account when creating their workflow.

Recipient

In the To field, enter the Gmail address where you want the automated message to be sent.

Workshop example:

test123@gmail.com

For the workshop demonstration, we can use one demo email address. In a real college automation, this could be changed depending on the selected department.

Configure the Gmail node to send an email message.

How it works:

The Form Trigger collects the student's information. n8n then passes that information to the Gmail node. The Gmail node uses the student's subject and message to automatically send the email.

Basic Automation Flow

You fill the form → n8n receives information → Gmail → Email sent

This is our first automation.

You do not need to manually open Gmail and compose an email.

n8n handles that process automatically.

Test the Workflow

  1. Open the form.
  2. Enter a student's email.
  3. Select a department.
  4. Enter an email subject.
  5. Enter a message.
  6. Submit the form.
  7. Check the Gmail inbox.
Success!

If the email arrives automatically, your first n8n automation is working.
