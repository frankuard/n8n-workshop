2. Configure the Gmail Account

Before using the Gmail node, n8n needs permission to access the Gmail account that will send the emails.

Important: The Gmail account connected to n8n is the account that will send the automated emails.

Step 1: Add the Gmail Node

Step 3: Connect Your Google Account

n8n ↓ Create Gmail Credential ↓ Google Sign-in ↓ Allow Required Permissions ↓ Gmail Account Connected

Review the permissions requested by n8n and allow the required permissions so n8n can send emails through the connected Gmail account.

Step 5: Select the Credential

Return to the Gmail node and select the Gmail credential you just created.

Example connected account:
example123@gmail.com

6. Add the Basic LLM Chain

Add a Basic LLM Chain to the workflow.

The student's What do you need? field will be provided to the AI as part of the prompt.

Then add a Groq Chat Model and connect it to the Basic LLM Chain.

📝 On Form Submission ↓ 🤖 Basic LLM Chain ↑ 🧠 Groq Chat Model ↓ 📧 Gmail
Important: The Groq Chat Model provides the AI model that the Basic LLM Chain uses to understand the student's request and generate the email.

Configure Groq

Before the Groq Chat Model can work, we need to connect a Groq API account to n8n.

Step 1: Create a Groq Account

Open the Groq Console and sign in or create an account.

Groq Console:

https://console.groq.com/

Step 2: Create an API Key

  1. Open the API Keys section in the Groq Console.
  2. Click Create API Key.
  3. Give the key a suitable name, such as n8n-workshop.
  4. Create the key and copy it immediately.
Security: Your Groq API key is private. Do not share it with other people, post it on GitHub, or put it directly into screenshots or public documents.

Step 3: Add the Groq Credential in n8n

Return to n8n and open the Groq Chat Model node.

  1. Find the Credential section.
  2. Click Create New Credential.
  3. Select the Groq credential option.
  4. Paste the API key you copied from the Groq Console.
  5. Save the credential.
Groq Console ↓ Create API Key ↓ Copy API Key ↓ n8n ↓ Groq Chat Model ↓ Create Credential ↓ Paste API Key ↓ Save

Step 4: Select the AI Model

After connecting the Groq credential, select a Groq chat model from the model field.

Example:

Select an available Groq chat model shown in your n8n model dropdown.
Note: Available models can change over time. During the workshop, select one of the currently available chat models shown in the Groq Chat Model node rather than relying on a specific model name.

Step 5: Connect Groq to the Basic LLM Chain

Connect the Groq Chat Model to the model input of the Basic LLM Chain.

📝 On Form Submission ↓ 🤖 Basic LLM Chain ↑ 🧠 Groq Chat Model

The Basic LLM Chain will now use the Groq model whenever it needs to generate a response.

Understanding the Connection

Basic LLM Chain

This controls what we want the AI to do.

In our workflow, it receives the student's request and the instructions from our prompt.

Groq Chat Model

This provides the AI model that performs the task.

It receives the prompt from the Basic LLM Chain and generates the professional email.

"The Basic LLM Chain tells the AI what to do, while the Groq Chat Model provides the AI that does it."

Complete AI Connection

📝 STUDENT FORM ↓ 📄 Student Request ↓ 🤖 BASIC LLM CHAIN ↑ 🧠 GROQ CHAT MODEL ↓ ✉️ AI-GENERATED EMAIL ↓ 📧 GMAIL

7. AI Prompt

Put the following prompt into the Prompt / User Message field.

You are an AI email assistant for college students. Your job is to take a student's request, question, complaint, or concern and turn it into a clear, polite, and professional email that can be sent to the college department or faculty selected by the student. Student Information: Name: {{ $json['Student Name'] }} Email: {{ $json['Student Email'] }} Department / Faculty: {{ $json['Department'] }} Subject: {{ $json['Subject'] }} Student's Request: {{ $json['What do you need help with?'] }} Instructions: 1. Carefully understand what the student is trying to communicate. 2. Rewrite the student's request into a clear, polite, and professional email suitable for communication with a college department or faculty. 3. Keep the student's original meaning and intention. Do not change what the student is asking for. 4. The request may involve any normal college-related matter, including leave requests, academic questions, examination issues, document requests, technical problems, fee-related questions, complaints, or general concerns. 5. Address the selected department or faculty appropriately. 6. Use a respectful, friendly, and professional tone. 7. Make the request clear and easy for the recipient to understand. 8. Do not invent information, policies, dates, decisions, excuses, or other details that the student did not provide. 9. Do not promise that the request will be approved or accepted. The selected department or faculty will make the final decision. 10. If the student's request is unclear, do not invent missing details. Keep the wording general and politely ask the department or faculty for clarification if necessary. 11. Keep the email reasonably concise. Do not make it unnecessarily long. 12. End the email politely with the student's name. 13. Return only the email body. 14. Do not include the subject line, explanation, analysis, or any additional commentary. The final output should be a natural, respectful email that is ready to be sent to the selected college department or faculty.

12. The Important Difference

Without AI

Student ↓ Writes complete email ↓ Selects department ↓ Form ↓ Gmail ↓ Department

The student is responsible for writing the complete email.

With AI

Student ↓ Explains what they need ↓ Selects department ↓ AI understands & formats request ↓ Gmail ↓ Department

The student only needs to explain what they need. AI handles the wording before the email is sent.

"In the first workflow, n8n automates the process of sending the information. In the second workflow, AI is added to understand the student's request and transform it into a professional email before n8n takes the final action."

13. What We Have Built

TRIGGER ↓ Student submits form ↓ INPUT ↓ Student's request ↓ AI PROCESSING ↓ AI understands and formats the request ↓ ACTION ↓ Gmail sends the email ↓ RESULT ↓ Selected college department receives the request
Key idea: This is more than simply connecting a form to Gmail. We are using AI as one part of an automated process to understand information and perform an action automatically.

16. Deploy n8n Locally with Docker & Cloudflare

In this final section, we will run n8n locally using Docker and make it accessible from the internet using Cloudflare Tunnel. This allows you to test webhooks and share your local n8n workflow temporarily without deploying n8n to a cloud server.

Important: Cloudflare Tunnel makes your local n8n instance accessible from the internet. Only use this for testing and workshop purposes. Do not expose sensitive workflows, credentials, or private information.

What We Are Building

Your Computer ↓ Docker ↓ n8n ↓ Cloudflare Tunnel ↓ Temporary Public URL

Step 1: Install Docker

First, install Docker on your computer. You need Docker before starting the n8n container.

Windows

Install Docker Desktop for Windows. After installation, open PowerShell or Windows Terminal and check: 

docker --version

You should see something similar to:

Docker version 28.x.x

macOS

Install Docker Desktop for Mac. Then open Terminal and run: 

docker --version

Linux

Install Docker using your Linux distribution's package manager or Docker's official installation instructions.

Then check:

docker --version
Make sure Docker is running before continuing.

Step 2: Create an n8n Folder

Open your terminal or command prompt and create a folder for n8n.

Windows PowerShell

mkdir n8n
cd n8n

macOS / Linux

mkdir n8n
cd n8n

You should now be inside your n8n folder.

Step 3: Run n8n with Docker

Run the following command: 

docker volume create n8n_data

docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

This downloads the n8n Docker image and starts n8n on your computer.

Windows users: If you are using Command Prompt instead of PowerShell, use this version: 
docker volume create n8n_data

docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

Step 4: Open n8n

Open your browser and visit: 

http://localhost:5678

Your n8n instance should now be running locally.

Remember: At this point, n8n is only accessible from your own computer.

Step 5: Install Cloudflare Tunnel

Now we will use Cloudflare Tunnel to create a temporary public URL that forwards traffic to your local n8n instance.

Windows

Install cloudflared, then verify the installation: 

cloudflared --version

macOS

If you use Homebrew: 

brew install cloudflared

Then check:

cloudflared --version

Linux

Install cloudflared using the package method for your Linux distribution, then check: 

cloudflared --version

Step 6: Create a Temporary Public URL

Make sure your Docker n8n container is running, then execute: 

cloudflared tunnel --url http://localhost:5678

Cloudflare will provide a temporary URL similar to: 

https://random-name.trycloudflare.com
Keep this terminal running. Closing the Cloudflare Tunnel process will stop the public connection.

Step 7: Access n8n Through the Tunnel

Copy the HTTPS URL shown by Cloudflare and open it in your browser. 

https://your-random-name.trycloudflare.com

You should now be able to access your locally running n8n instance through the temporary public URL.

Step 8: Test Your Workshop Workflow

Now return to the workflow you created during the workshop. If your workflow uses a webhook or form trigger, use the public Cloudflare URL when required.

Student ↓ n8n Form / Webhook ↓ AI / Groq ↓ Gmail ↓ Optional Discord

Useful Docker Commands

These commands will help you manage your local n8n instance.

Command Purpose
docker ps Check running containers
docker stop n8n Stop n8n
docker start n8n Start n8n again
docker restart n8n Restart n8n
docker logs n8n View n8n logs
docker stop n8n Stop the container
docker rm n8n Remove the container

Stopping Everything

When you finish testing, stop n8n: 

docker stop n8n

Then stop the Cloudflare Tunnel by pressing: 

Ctrl + C
Important: The Cloudflare URL created by this method is temporary. It can change when you create a new tunnel session. This setup is intended for testing and workshops, not permanent production hosting.
